# 해온동 PC 게임

Godot 4로 실행하는 해온동 생활·사회 시뮬레이션입니다. 기본 대화는 외부 네트워크 없이 동작하며, Ollama와 로컬 모델이 준비되어 있으면 입력한 문장에 맞춘 주민 대화를 이 PC에서 생성합니다.

## 실행

저장소 루트에서 다음 명령으로 실행합니다.

```powershell
& ".\godot\.tools\Godot_v4.7.2-stable_win64.exe" --path ".\godot"
```

## 자연어 대화

Ollama가 없어도 대화창에 문장을 쓸 수 있습니다. 인사, 취향, 동네 소식, 약속, 중재와 관련된 표현은 게임 규칙으로 처리하고, 그 외 문장에는 주민의 취향을 반영한 기본 답변을 보여줍니다.

## Ollama 로컬 대화

1. [Ollama for Windows](https://ollama.com/download/windows)를 설치하고 실행합니다.
2. PowerShell에서 작은 기본 모델을 한 번 내려받습니다.

   ```powershell
   ollama run gemma3:1b
   ```

   `gemma3:1b` 모델 파일은 약 806MB입니다. 첫 다운로드 뒤에는 Ollama의 로컬 API가 `127.0.0.1:11434`에서 동작해야 합니다.
3. Ollama를 먼저 실행한 상태에서 게임을 시작합니다.

```powershell
& ".\godot\.tools\Godot_v4.7.2-stable_win64.exe" --path ".\godot"
```

게임은 시작할 때 `gemma3:1b`가 설치되어 있는지 확인합니다. Ollama 또는 모델이 없다면 자동 다운로드하지 않고 기본 대화로 시작합니다. 설치·실행 후 게임을 다시 열면 로컬 모델을 사용합니다.

Ollama를 사용해도 플레이어 문장과 주민의 공개 프로필은 이 PC의 `127.0.0.1`로만 전송됩니다. 게임은 비공개 고민과 저장된 NPC 기억을 요청에 넣지 않습니다. 대화 모델의 응답은 말풍선에만 쓰이고, 관계·기억·약속·경제 상태는 게임 규칙만 변경합니다.

## 성능 참고

`gemma3:1b`는 로컬 실행을 확인하기 위한 작은 기본 모델입니다. 8GB 메모리 PC에서 실제 응답 속도와 한국어 대화 품질은 환경에 따라 달라지며, 이 PC에서 아직 측정하지 않았습니다. 게임은 Ollama에 2K 문맥과 짧은 답변을 요청합니다. Ollama가 응답하지 않거나 오류가 생기면 기본 대화로 전환합니다.
