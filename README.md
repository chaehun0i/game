# game — 해온동

당신이 없을 때도 이곳의 사람들은 살아가는 생활·사회 시뮬레이션입니다. P1 확장을 진행 중이며, 현재 열 명의 이웃과 규칙 기반 생활·직업·경제 루프를 서버나 외부 AI 없이 브라우저에서 실행합니다.

## 실행

Node.js 20 이상이 있으면 `npm test`로 시뮬레이션 단위 테스트를 실행할 수 있습니다. 게임은 `npm start` 후 브라우저에서 `http://localhost:4173`을 여세요. 설치 단계나 네트워크 의존성은 없습니다. iPhone에서 접속하려면 같은 Wi-Fi의 PC 주소로 접속해야 하며, 로컬 저장소는 해당 브라우저에 남습니다.

세계 상태는 브라우저 로컬 저장소에 자동 저장되고 이전 정상 저장본도 함께 보관합니다. 저장 파일이 손상되면 백업본 복구를 시도합니다.

## 조작

지도에서 장소를 눌러 이동하거나 방향키/WASD·화면 이동 버튼으로 걸어 다닙니다. 지도 위 이웃이나 오른쪽 이웃 카드를 누르면 그 사람에게 다가가 대화할 수 있습니다. `1` 카페에서 일하기, `2` 현재 장소의 이웃과 대화하기, `3` 집에서 쉬기, `4` 도서관에서 책 읽기, `5` 카페에서 식사하기, `6` 지금 있는 장소의 활동입니다. 해당 장소에 도착해야 행동할 수 있으며 이동에는 게임 시간이 들지 않습니다. 저장은 브라우저 로컬 저장소에 자동으로 이뤄집니다.

개발자 확인 도구는 `http://localhost:4173/?dev=1`에서 열 수 있습니다. 하루/한 시간 진행, 시드 조정, NPC 상태 확인이 가능합니다. 새 저장으로 특정 시드를 시작하려면 `?dev=1&seed=123`처럼 접속하세요.

현재 구현은 한 동네, 이웃 10명, 장소별 일정, 급여와 식사 지출, 플레이어 허기·식사, 장소에 따라 달라지는 생활 활동, 7일 단위 계절, 다음 날 약속, 관계·기억·소문·오해·화해 루프와 기본 모바일·접근성 지원입니다. P1 장기 검증과 P2/P3 확장은 계속 진행 중입니다. 외부 플레이테스트와 iPhone 실기기 검증은 아직 하지 않았습니다. P0 재미 검증도 아직 NOT YET VERIFIED입니다.
